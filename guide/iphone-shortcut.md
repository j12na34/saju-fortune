# 아이폰 단축어 설정 안내 (쉬운 버전)

단축어 앱의 동작 이름은 아이폰 iOS 버전·언어에 따라 조금 다를 수 있어요. 안 보이면 상단 검색창에 비슷한 말을 쳐 보세요.

## 0단계. 먼저 "배경화면을 단축어로 바꿀 수 있는지" 시험하기 (5분)

1. **단축어** 앱 → 오른쪽 위 **+** → 새 단축어.
2. 검색창에 `배경화면`을 입력합니다.
3. 결과에 **"배경화면 설정"** 비슷한 동작이 있으면 눌러서 추가합니다.
4. 사진 하나를 골라 연결하고 ▶(재생)을 눌러 배경화면이 실제로 바뀌는지 봅니다.

결과를 알려 주세요.
- **바뀐다** → 아래 1단계로 갑니다.
- **동작이 없거나 안 바뀐다** → 아래 "대안"을 보세요.

## 1단계. 오늘의 색 받아오기

새 단축어에 아래 동작을 순서대로 추가합니다.

1. **URL의 콘텐츠 가져오기** → `https://j12na34.github.io/saju-fortune/fortune.json`
2. **사전에서 값 가져오기** → 키 `summary` (알림용)
3. **현재 날짜** → 형식을 "시"만 나오게 → 숫자 변수 `시각`
4. **조건(만약)**: `시각`이 7 이상 12 미만이면 `morning`, 12 이상 18 미만이면 `lunch`, 아니면 `evening` 을 변수 `시간대`에 저장
5. **사전에서 값 가져오기** → `slots` → `시간대` → `color` → `hex`

## 2단계. 단색 이미지 만들기

단축어에는 "단색 이미지 만들기" 동작이 기본으로 없는 경우가 많아요. 두 가지 방법을 시험해 보세요.

- **방법 A:** `URL의 콘텐츠 가져오기`로 단색 이미지를 돌려주는 주소를 부릅니다. 예: `https://singlecolorimage.com/get/<hex에서 # 뺀 값>/1170x2532` (외부 서비스라 언제든 사라질 수 있어요)
- **방법 B (추천, 외부 의존 없음):** 이 저장소가 색 이미지를 `docs/colors/`에 직접 올려 주도록 제가 나중에 추가할 수 있어요. 필요하면 말씀해 주세요.

## 3단계. 배경화면 바꾸고 알림 띄우기

1. **배경화면 설정**에 만든 이미지를 연결합니다. ("미리보기 보기"는 끄기)
2. **알림 보기** → 1단계의 `summary`를 내용으로.

## 4단계. 자동으로 돌리기

단축어 앱 → **자동화** → **+** → **개인용 자동화** → **특정 시간** 3개를 만듭니다: **07:30, 12:30, 18:30** (운세 갱신이 5~10분 늦을 수 있어서 여유를 두었어요).
각각 위 단축어를 실행하게 하고 **"실행 전에 묻기"를 끕니다.**

## 대안 (배경화면 동작이 없을 때)

- 이미지를 **사진 앱에 저장**하고 알림으로 "오늘의 색이 도착했어요"를 띄운 뒤, 직접 배경화면으로 지정합니다.
- 또는 알림만 받습니다. (색 이름·이유는 `fortune.json`의 `slots.<시간대>.color`에 있어요)

## 확인

예약 시간이 지난 뒤 배경화면과 알림이 바뀌었는지 보고 알려 주세요. 안 바뀌었다면 어느 단계에서 멈추는지(화면 사진이나 오류 문구)를 알려 주시면 됩니다.
