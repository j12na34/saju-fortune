# 내 사주 웹앱 설계

## 목표
궁금할 때 열어서 연애운·재물운·직장운·건강운·대인운을 보는 모바일 우선 웹앱(참고: umg.kr).
내 사주(`chart.json`) 전용이라 입력·로그인이 없다.

## 확정 사항 (사용자 위임으로 추천안 채택)
- 글은 **미리 생성**: 기존 Routines(07:00 full)가 주제별 글을 `docs/fortune.json` 의 `topics` 에 함께 쓴다. 서버·API 키 없음.
- 점수·근거는 **코드가 결정적으로 계산**한다(`saju/topics.py`). AI는 근거 문장만 풀어 쓴다.
- 글이 아직 없을 때(Routines 실패 등)는 코드가 만든 근거 문장(`facts`)을 앱이 대신 보여 준다. 화면이 비지 않는다.
- 기존 필드(`date`, `slots`, `summary` …)는 그대로 둬서 아이폰 단축어가 깨지지 않는다. `topics` 는 추가 항목이다.
- 호스팅은 기존 GitHub Pages(`/docs`). 정적 HTML/CSS/JS, 빌드 도구 없음.

## 점수 규칙 (일간 庚금 기준, 기본 60점, 30~95로 제한)
오늘 일진의 천간·지지 오행과 원국과의 관계로 가감한다. 의학·투자 단정 표현은 쓰지 않는다.
- 재물: 일진에 木(재성) +8/글자, 金(비겁, 재물을 나눔) −5/글자
- 직장: 火(관성) +8/글자, 土(인성) +4/글자, 水(식상, 관을 누름) −5/글자
- 연애: 일지(戌)와 오늘 지지가 육합 +15, 충 −15 / 일간과 오늘 천간이 합 +10 / 木·火 +3/글자
- 건강: 필요 오행(원국+일진에서 가장 적은 오행)이 일진에 있으면 +10/글자, 金 과다(원국+일진 金 4개 이상) −8
- 대인: 오늘 천간이 일간과 합 +10, 오늘 지지가 원국 지지와 육합 +6/건, 충 −6/건, 金(비겁) +4/글자

## 데이터
`fortune.json` 의 선택 항목:
```json
"topics": {"love": {"label": "연애운", "score": 72, "text": "글", "facts": ["근거 문장"]}, "...": {}}
```
키: `love, money, work, health, people`. `topics` 가 있으면 5개 모두 필요하고 score 는 0~100 정수.

## 화면
- 상단: 날짜·일진, 오늘의 색(3시간대 칩), 전체 운세.
- 주제 탭(연애/재물/직장/건강/대인): 점수 링, 한줄 글, 근거 목록.
- 시간대별 카드(아침/점심/저녁) + 색 이유.
- 날짜가 오늘이 아니면 "갱신 전" 배지. 데이터 로드 실패 시 안내 문구.
- 다크 모드, 모바일 360px 폭 기준.

## 테스트
- 점수: 같은 입력은 같은 결과, 범위 30~95, 알려진 합·충 사례.
- publish/validate: topics 있을 때 검사, 없을 때 기존 동작 유지.
- 앱: 정적 파일이므로 Playwright(Chromium)로 스크린샷 확인.
