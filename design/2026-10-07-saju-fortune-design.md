# 사주 일일 운세 + 아이폰 배경화면 자동화 설계

## 목표
하루 3번(07:00, 12:00, 18:00 KST) 사주 기반 운세와 행운 색을 `fortune.json`으로 공개하고,
아이폰 단축어가 그 파일을 읽어 단색 배경화면을 바꾸고 summary를 알림으로 띄운다.

## 확정 사항
- 원국: 년주 己卯, 월주 壬申, 일주 庚戌, 시주 壬午 (일간 庚금). 진태양시 보정 12:38 적용.
- 저장소는 공개. 생년월일·출생시는 저장소에 올리지 않고 간지만 `chart.json`에 둔다.
- 사주 계산은 lunar-python 코드가 하고 AI는 계산 결과를 근거로 글·색 설명만 쓴다.
- 시간대: 아침 07~12, 점심 12~18, 저녁 18~다음날 07.
- 07:00 실행: 전체 운세 + 세 시간대 글 + 잠정 색 3개. 12:00/18:00 실행: 해당 시간대만 시간 간지로 갱신.
- 색: 원국 오행 부족/과다를 일진이 어떻게 바꾸는지 보고 보완 오행의 색을 고른다. 세 시간대는 같은 계열에서 밝기·채도만 다르게.
- 실행 방식: Routines(Claude 세션)가 엔진을 실행하고 `fortune.json`을 main에 푸시, Pages가 공개.

## 구조
```
chart.json          원국 간지 (개인정보 없음)
docs/fortune.json   Pages가 공개하는 결과
saju/engine.py      간지·오행·색 후보 계산
saju/cli.py         오늘 분석 결과를 JSON으로 출력
saju/validate.py    fortune.json 형식 검사
tests/              간지 대조·오행·색·형식 테스트
design/             설계 문서
```
공개 주소: `https://j12na34.github.io/saju-fortune/fortune.json` (main 브랜치 `/docs`).

## fortune.json
```json
{
  "date": "YYYY-MM-DD",
  "updated_at": "ISO8601+09:00",
  "ilgin": "일진 간지",
  "overall": "전체 운세",
  "slots": {
    "morning": {"text": "", "color": {"hex": "#RRGGBB", "name": "", "reason": ""}},
    "lunch":   {"text": "", "color": {"hex": "#RRGGBB", "name": "", "reason": ""}},
    "evening": {"text": "", "color": {"hex": "#RRGGBB", "name": "", "reason": ""}}
  },
  "summary": "알림용 한두 줄"
}
```

## 오류 처리
- 저장 전 검사: 필수 항목 누락이나 hex 형식 오류면 저장하지 않고 이전 파일 유지.
- 12시/18시 실패 시 07시의 잠정 값이 남아 배경화면은 항상 나온다.
- 단축어는 `date`가 오늘이 아니면 "갱신 전"으로 처리.
- 푸시 전에 최신 main을 받아 겹침 충돌을 피한다.

## 테스트
- 날짜 없이 간지 결과만 쓰는 테스트 + 공개 만세력으로 확인 가능한 알려진 날짜들
  (입춘 전후 년주, 절기 경계 월주, 자시 경계 일주).
- 오행 개수·색 선택은 같은 입력이면 항상 같은 결과(결정적).
- 원국 계산은 개인 생년월일시로 대화 중 한 번만 실행하고 간지만 `chart.json`에 저장. 생년월일시는 파일에 남기지 않는다.

## 단계
1. 저장소 구조 + Pages 설정, 공개 주소에서 `fortune.json` 열리는지 확인.
2. 사주 엔진 + 간지 대조 검증.
3. Routines 3개 예약 설정.
4. 아이폰 단축어 안내 (배경화면 직접 변경 가능 여부를 먼저 테스트).
